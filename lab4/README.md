# Лабораторная работа 4

Консольное приложение "Дневник", собранное с использованием Kubernetis

## 1: Сборка приложения

```bash
chmod +x build.sh
./build.sh
```

## 2: Запуск собранного приложения

```bash
chmod +x run.sh
./run.sh
```


Скрины, подтверждающие работоспособность находятся в поддиректории `doc`
